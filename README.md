# AFJCode

Site institucional da **AFJCode**, empresa de desenvolvimento de software fundada por Arthur, Fernando e Júlia.

Página única (single-page) apresentando a empresa, os serviços oferecidos, os sócios e os canais de contato.

## Serviços

- Sites institucionais e landing pages
- Aplicativos mobile e web
- Sistemas internos sob medida

Todos os projetos são desenvolvidos sob demanda, de acordo com a necessidade de cada negócio.

## Estrutura do projeto

```
├── index.html      # Estrutura e conteúdo da página
├── style.css       # Estilos (tema escuro, gradiente ciano/azul/roxo)
├── script.js       # Interações: menu mobile, scroll reveal, animação do hero
└── img/
    ├── logo.webp           # Monograma "AFJ"
    ├── logo-lockup.webp    # Logo completa (ícone + "AFJCode")
    ├── favicon.webp        # Ícone da aba do navegador
    ├── arthur.webp         # Foto do sócio Arthur
    └── fernando.webp       # Foto do sócio Fernando
```

> Foto da Júlia ainda pendente — o card dela usa um avatar provisório com a inicial "J".

## Tecnologias

- HTML, CSS e JavaScript puro (sem frameworks ou build step)
- Fontes: [Sora](https://fonts.google.com/specimen/Sora), [Manrope](https://fonts.google.com/specimen/Manrope) e [JetBrains Mono](https://fonts.google.com/specimen/JetBrains+Mono), via Google Fonts

## Rodando localmente

Não há dependências nem build. Basta abrir o `index.html` diretamente no navegador, ou servir a pasta com qualquer servidor estático simples.

## Deploy

O site é publicado via [GitHub Pages](https://pages.github.com/), direto a partir deste repositório.
